# Security Rules

Nicht committen:

- Passwörter
- Tokens
- API Keys
- private Schlüssel
- sensible personenbezogene Daten
- vertrauliche Firmeninformationen, sofern nicht ausdrücklich vorgesehen

Secrets ausschließlich über geeignete Secret Stores oder Umgebungsvariablen verwalten.

Neue Dependencies müssen auf Nutzen, Lizenz, Wartungszustand und Sicherheitsrisiken geprüft werden.
