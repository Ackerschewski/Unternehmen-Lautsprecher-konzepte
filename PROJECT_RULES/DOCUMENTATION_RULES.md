# Documentation Rules

Es gibt zwei getrennte Dokumentationsebenen.

## Benutzer
Bedienung, Installation, Workflows, Beispiele, Troubleshooting.

## Entwickler/Wartung
Architektur, Module, Datenfluss, Interfaces, Algorithmen, Tests, Debugging, Build, Releases und Erweiterung.

Verhaltensänderungen müssen zusammen mit der Dokumentation aktualisiert werden.
