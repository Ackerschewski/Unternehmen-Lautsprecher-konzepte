# Non-Goals

Explizite Nicht-Ziele verhindern Scope Creep.

- Kein Ersatz für Messung: Das Programm trifft keine Freigabe für Sicherheits- oder Leistungsfragen.
- Keine Schätzung fehlender Chassis-, Maß- oder Preisdaten.
- Keine Cloud-Anbindung, kein Konto, keine Telemetrie.
- Kein Mehrbenutzer- oder Netzwerkbetrieb.
- Keine automatische Montage-, Bestell- oder Veröffentlichungsfunktion.
- Kein CAD-Ersatz: Zeichnungen sind Fertigungsunterlagen für Rohplatten, keine vollständigen 3D-Modelle.
