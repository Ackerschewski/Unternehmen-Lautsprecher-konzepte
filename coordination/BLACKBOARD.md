## Rule

Strukturierte Daten gehören nicht doppelt hier hinein.

- Agent-Status → `PROJECT_STATE.yaml`
- Tasks → `coordination/tasks/`
- offene Fragen → `OPEN_QUESTIONS.md`
- Integration → `INTEGRATION_QUEUE.md`
- Releases → `RELEASE_CHECKLIST.md`
- Repository-Klassifikation → `REPOSITORY_METADATA.yaml`

Das Dashboard zieht diese Informationen automatisch zusammen.
