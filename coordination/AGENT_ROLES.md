# Agent Roles

## Agent 1 – Architecture & Core
Architektur, Datenmodelle, Interfaces, Modulgrenzen, ADRs.

## Agent 2 – Features & Algorithms
Fachlogik, Algorithmen, Berechnungen und Kernfeatures.

## Agent 3 – UI & UX
Panels, Dialoge, Workflows, Benutzerführung und Darstellung.

## Agent 4 – Platform & Integration
Host-APIs, externe Systeme, Adapter, Dateisystem- und Plattformintegration.

## Agent 5 – QA & Integration
Tests, Regression, Integration, Merge Queue, Release Candidate und Dokumentationsprüfung.

Rollen dürfen projektspezifisch angepasst werden, müssen aber dokumentiert werden.
